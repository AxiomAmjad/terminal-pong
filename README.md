# Terminal Pong

A two-player Pong game for the Linux terminal, written in Python with `curses`.

## Run

    python3 pong.py

## Controls

- Left paddle: `w` / `s`
- Right paddle: up / down arrows
- Pause: `p`
- Quit: `q`

## Notes

Needs a terminal of at least 40x15. The ball speeds up with each hit, and where it lands on the paddle changes its angle.
